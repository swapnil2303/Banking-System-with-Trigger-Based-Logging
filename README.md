# Banking System GUI with Trigger-Based Logging

This project is a simple banking system developed by **Swapnil Jaiswal** using Python, Tkinter, and SQL Server. It features a graphical user interface (GUI) that allows users to manage customer accounts and automatically logs all database operations using SQL triggers.

---

## 📌 Project Overview

The system allows users to:
- Add new customers
- Update customer balances (deposit/withdraw)
- Delete customers
- View all customers
- View transaction logs

All changes to the database are automatically recorded in a log table using SQL Server triggers.

---

## 🚀 Features

- GUI built with Tkinter
- SQL Server backend with trigger-based logging
- Insert, update, delete operations with automatic logging
- View logs of all actions performed
- Real-time database interaction

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** (for GUI)
- **SQL Server** (for database)
- **pyodbc** (for database connectivity)
